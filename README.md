# 📖 Scogna Manga Reader
![Vercel](https://therealsujitk-vercel-badge.vercel.app/?app=scogna-manga-reader)
Benvenuto su **Scogna Manga Reader**! Questa è un'applicazione web creata per farti leggere i tuoi manga preferiti in modo semplice, veloce e comodo, sia dal computer che dal telefono.
A modern, fast, and responsive web application to read your favorite manga seamlessly. Built with **React**, **Vite**, and **TailwindCSS**, optimized for both desktop and mobile devices.
🌐 **Clicca qui per usare l'app:** [https://scogna-manga-reader.vercel.app/](https://scogna-manga-reader.vercel.app/)
🌐 **Live Demo:** [https://scogna-manga-reader.vercel.app/](https://scogna-manga-reader.vercel.app/)

## ✨ Features
- **Lettura a scorrimento verticale**: Leggi i manga scorrendo verso il basso, proprio come faresti con un Webtoon o sui social network. Niente più click per cambiare pagina!
- **Zoom facile dal telefono**: Usa comodamente due dita per ingrandire i disegni e un dito per spostarti nell'immagine senza impazzire.
- **Ricerca intelligente**: Trova subito il manga che vuoi leggere digitando il titolo.
- **Libreria e Cronologia**: Salva i manga che ti piacciono nella tua "Libreria" e riprendi la lettura esattamente da dove l'avevi lasciata grazie alla "Cronologia" automatica.
- **Webtoon-Style Reading**: Vertical, infinite scrolling for an immersive reading experience.
- **Advanced Touch Gestures**: Mobile-first design with two-finger zoom and one-finger panning support, bypassing native browser limitations for a fluid experience.
- **Smart Search**: Find any manga instantly using the integrated advanced search.
- **Library & History**: Save your favorite manga to your Library and automatically track your reading history so you never lose your place.
- **Seamless Serverless Proxy**: Powered by Vercel Rewrites to securely and efficiently bypass CORS restrictions without the need for a dedicated backend server.

## 🚀 Tech Stack
Se vuoi scaricare questo progetto e farlo funzionare sul tuo computer per fare delle modifiche, segui questi 3 semplici passi:
- **Frontend**: React 18, React Router DOM, Zustand (State Management)
- **Styling**: TailwindCSS, Lucide React (Icons)
- **Gestures**: React-Zoom-Pan-Pinch
- **Build Tool**: Vite
- **Deployment**: Vercel (Serverless Edge Network)
